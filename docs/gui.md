# core-agent — GUI版

ブラウザで使う版です。TUI(ターミナルREPL)版は [`docs/tui.md`](./tui.md) を参照してください。
バックエンド(ツール・セッション管理・LLM接続)はTUIと完全に共有しており、`cli.ts`(TUI)と
`webServer.ts`(GUI)は対等な2つの入口です。

## インストール

Node.js 18以上(`fetch`/`ReadableStream`をネイティブ利用)が必要です。

```bash
npm install
cp .env.example .env
```

`.env`を編集して、最低限メインモデルのエンドポイントを設定してください:

```bash
# メインモデル(コーディング用、OpenAI互換)
OPENAI_BASE_URL=http://127.0.0.1:8000/v1
OPENAI_API_KEY=
LLM_MODEL=deepseek-v4-flash
# Anthropic互換(/v1/messages)にしたい場合のみ
LLM_PROTOCOL=openai

# Vision fallback(任意。view_imageツールを使う場合のみ必要)
VISION_BASE_URL=
VISION_API_KEY=
VISION_MODEL=
```

`google_search`/`visit_page`ツールはインストール済みのGoogle Chromeを操作します。詳細・初回の
ウォームアップ手順はTUI版と共通なので [`docs/tui.md`](./tui.md#googlesearchを初めて使う場合重要)
を参照してください。

## 起動

```bash
npm run dev:gui
```

```
core-agent GUI — model: deepseek-v4-flash @ http://127.0.0.1:8000/v1
Listening on http://0.0.0.0:8787 (no auth — trusted networks only)
```

ブラウザで `http://localhost:8787` を開いてください。同じLAN内の別端末(スマホ・別PC)から
使いたい場合は、その端末のブラウザで `http://<このPCのIP>:8787` を開けば同様に使えます。

### ⚠️ 認証はありません

GUIサーバーには**認証機構が一切ありません**。既定で全ネットワークインターフェース
(`0.0.0.0`)で待ち受けるため、同じLAN上の誰でもアクセスでき、`bash`ツール等の強力な機能を
操作できてしまいます。**信頼できるネットワーク上でのみ**起動してください。同一マシンからしか
使わない場合は`.env`で`GUI_HOST=127.0.0.1`に変更することを推奨します。

### GUI専用の環境変数

| 変数名 | 既定値 | 説明 |
|---|---|---|
| `GUI_HOST` | `0.0.0.0` | 待受アドレス。同一マシンのみに絞るなら`127.0.0.1` |
| `GUI_PORT` | `8787` | 待受ポート |
| `GUI_INLINE_MEDIA` | `1`(有効) | 画像/動画/音声をセッション内にインライン表示するか。`0`にすると、GUIサーバーを起動しているマシン側でネイティブアプリが開く(TUIの`show_media`と同じ動作)にフォールバックする |

## 画面の使い方

### サイドバー(左)

- モデル名・エンドポイント・読み込まれたskills/hooks/cron件数を表示
- セッション一覧(クリックで切替)・「+ New session」で新規作成
- 「Tools」パネル(折りたたみ)でエージェントが使えるツール一覧を表示
- サイドバー自体は左上の«ボタンで開閉可能

### ヘッダー(セッション名の行)

| 要素 | 説明 |
|---|---|
| `tools`チェックボックス | `[tool call]`/`[tool result]`の詳細ログの表示/非表示(既定OFF)。会話の邪魔になる時に |
| `auto`チェックボックス | 確認ゲート(y/N)のON/OFFをトグル |
| `reset`ボタン | 現在のセッションの会話履歴をクリア |
| ⌃(右端) | ヘッダー自体を折りたたむ(右上のフローティング⌄ボタンで再展開) |

### メッセージ入力

- Enterで送信、Shift+Enterで改行
- **IME(日本語入力)にネイティブ対応**しています(そもそもGUI版を作った動機です。TUIの
  IME折り返し問題はここでは発生しません)
- `!<command>` でシェルコマンドを直接実行(モデルを介さない)。`!cd <dir>`はそのセッションの
  作業ディレクトリだけを変更します(他のセッション・TUIには影響しません)
- `/help`または`/?`でコマンド一覧とツール一覧を表示(モデルを呼ばない、Markdownの表として表示)
- 応答生成中は画面下に「Stop」ボタンが出て中断可能(**Esc**キーでも中断できます)

### ドラッグ&ドロップ

画像・動画・その他ファイルをウィンドウ内にドロップすると、アップロードされて入力欄の上に
アイコン/サムネイルのチップとして表示されます(画像はサムネイル、それ以外は📄アイコン)。
チップの×で送信前に削除できます。送信すると、実際のファイルパスがメッセージ本文に
自動的に織り込まれ、モデルが`view_image`/`show_media`等で扱えるようになります。

### 確認モーダル

`write`/`edit`/`bash`(・skillツール)は既定で実行前に確認モーダルが出ます。TUIと同じ
`y`(承認)/`N`(拒否)/`a`(承認+以降は自動承認)のキー操作にそのまま対応しています
(マウスクリックも可)。長いコマンドはタイトル部分を160文字で省略し、続きは下のプレビュー欄に
表示されます。

### 画像/動画/音声のインライン表示

`show_media`ツールが呼ばれると、対応するファイル形式(画像・動画・音声)はセッション内に
直接埋め込んで表示されます(サーバーマシン側でアプリを開くTUIの動作とは異なります)。

- 画像はクリックでライトボックス全画面表示、動画は右上の⛶ボタンで全画面表示
- 各プレビューにはダウンロードリンク(⬇)が付きます(ファイルの実体はサーバーマシン上に
  しか無いため、手元に保存する唯一の手段です)
- PDF等、画像/動画/音声以外の形式は📄アイコン+ダウンロードリンクにフォールバックします
  (フルの文書ビューアは実装していません)
- `GUI_INLINE_MEDIA=0`にすると、この機能は無効化され、代わりにTUIと同じ
  「サーバーマシン側でネイティブアプリを開く」動作になります

## Hooks・skill機構・cron

TUI版と完全に同じ仕組みを共有しています。詳細は [`docs/tui.md`](./tui.md#hooks) を参照してください。

- **cronの重要な注意**: `.core-agent/cron.json`のジョブは、GUIサーバー自体が起動時に
  自動でスケジュールします(別途TUIの`--cron`を立てる必要はありません)。**TUIとGUIを
  同時に起動していると同じジョブが二重登録され、同じ通知が複数回発火することがあるので
  注意してください**(cronを使うなら、TUI/GUIどちらか一方だけを起動しっぱなしにしてください)。

## 既知の制限

- **認証なし**: 上記「⚠️ 認証はありません」参照。
- **`show_media`のサーバー側フォールバック**: `GUI_INLINE_MEDIA=0`の場合、`show_media`は
  GUIサーバーを起動しているマシン側でネイティブアプリを開きます。LAN越しに別端末の
  ブラウザから使っている場合、そちらの端末には何も表示されません。
- TUI版と共通の制限(KVキャッシュ非対応・think-mode非対応等)は
  [`docs/tui.md`](./tui.md#既知の制限) を参照してください。
